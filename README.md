# CIP — Gestão Comunitária

MVP de gestão comunitária desenvolvido para o Projeto Prático de Extensão Curricularizada.

## Objetivo
Organizar, em uma interface única, o cadastro de participantes, a inscrição em cursos, o registro de presença e indicadores básicos de acompanhamento.

## Funcionalidades
- Painel com indicadores do MVP
- Cadastro e edição de participantes
- Inscrição de participantes em múltiplos cursos
- Cadastro demonstrativo de cursos
- Chamada por curso e data
- Download da lista de inscritos de cada curso em CSV
- Download da chamada por curso/data em CSV
- Relatório de frequência
- Exportação e importação de backup em JSON
- Dados fictícios para demonstração

## Cursos demonstrativos
- Capoeira
- Hip Hop
- Dança do Ventre
- Samba
- SambaRock
- Informática (planejado)

## Tecnologias
HTML5, CSS3 e JavaScript, sem dependências externas.

## Importante
Este repositório representa um MVP/protótipo local. Os dados iniciais são fictícios e ficam no navegador. Uma implantação real deve incluir autenticação, perfis de acesso, banco de dados, backup e medidas de proteção de dados.

## Execução
Abra `projeto_cip/index.html` em um navegador.

## Estrutura
- `projeto_cip/index.html` — aplicação
- `projeto_cip/COMO_ABRIR.txt` — instruções rápidas
- `docs/` — documentação do projeto
